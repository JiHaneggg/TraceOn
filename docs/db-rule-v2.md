# DB·룰 2차 평가 기록 — 2026-11-14

## 결과

기존 룰과 개선 후보를 동일한 신규 최종평가 250건에서 비교했다. 세탁 표본은 100건, 정상 표본은 150건이다. 표본의 세탁 비율은 원본보다 높으므로 아래 주요 지표는 추출 확률의 역수로 보정한 추정치다.

| 지표 | 기존 설정 | 개선 후보 |
|---|---:|---:|
| Recall | 0.98% | 87.42% |
| Precision | 100.00% | 0.16% |
| 정상 거래 오탐률 | 0.00% | 66.00% |
| 추정 알림 비율 | 0.0012% | 66.03% |

| 표본 건수 | 기존 설정 | 개선 후보 |
|---|---:|---:|
| 정탐 TP | 1 | 88 |
| 미탐 FN | 99 | 12 |
| 오탐 FP | 0 | 99 |
| 정상 TN | 150 | 51 |

Recall은 개선됐지만 최종평가에서 목표 90%에 도달하지 못했고 정상 거래의 66%를 의심으로 분류했다. 개선 후보를 최종 운영 기준으로 채택하지 않는다. ML과의 결합 및 추가 특성 검증이 필요하다. 기존 설정의 Precision 100%는 이 표본에서 단 1건을 탐지한 결과로 안정적인 성능을 뜻하지 않는다.

## 고정한 설정

```json

  "min_counterparties": 3,

  "max_cycle_hops": 4,
  "threshold": 65,
  "fan_in_min_counterparties": 2,
  "fan_out_min_counterparties": 12
```

집금과 분산의 상대 계좌 수 기준을 분리했다. 점수 기준 75가 점수 65인 집금·분산 룰을 모두 막는 문제를 피하기 위해 V2 탐색에서는 점수 기준을 65로 고정하고 증거 조건을 조절했다. 시간 창 1·3·7일, 최대 순환 길이 4·6홉, 집금·분산 상대 계좌 수 각각 2·3·5·8·12·20을 사전에 정해 216개 조합을 비교했다.

## 데이터 분리와 재현

- 전처리 전체 5,078,345건의 디스크 인덱스로 과거 서브그래프를 준비했다. 이 인덱스는 오프라인 평가 도구이며 운영 DB는 Neo4j다.
- 검증 시작: 2022-09-06T13:36:00. 최종평가 시작: 2022-09-08T16:12:00.
- 거래 수 기준 60/20/20 경계 시각을 사용하며 같은 분의 거래는 경계 한쪽에만 둔다. 앞 60%는 향후 ML 학습 영역으로 남긴다.
- 검증 250건과 최종평가 250건, 총 500건. 각 구간에서 8개 패턴과 패턴 미지정 세탁 거래를 층화 추출했다.
- 기존에 노출된 거래 1,902건 및 패턴 가족 17개를 대상 추출에서 제외했다.
- 최종평가 패턴은 최종평가 시작 이후에 시작된 가족만 포함했다. 검증·최종평가 간 패턴 가족 중복은 0개다. 역사적 입력 거래·계좌의 중복은 허용한다.
- 검증 파일만 읽어 조건을 선택하고 설정·규칙 코드·데이터 해시를 고정했다. 그 다음 최종평가를 한 번 실행했으며 이 결과에 맞춰 조건을 다시 바꾸지 않았다.
- 최종평가 172/250개 그래프에서 조회 수 제한이 발생했다. 입력에는 과거 7일, 2홉, 계좌별 최근 50거래, 최대 1,000거래 제한이 있다.
- 정답·패턴 유형은 평가 메타데이터에만 있고 룰 입력에는 없다. 금액은 원본 문자열을 보존한다.
- 보정 지표의 대상 모집단은 위 제외·시간·패턴 가족 조건을 통과한 거래다. 전체 은행·전체 HI-Small 성능으로 일반화하지 않는다. 정상 표본 150건, 희소 유형별 표본은 작아 추정 불확실성이 크다.
