# 순환 유형 공식 근거와 검수 준비 — 2026-11-15

공식 자료를 8문서·50청크에서 **10문서·30절·61청크**로 확대했다. 기존 50청크의 ID·본문·해시와 이전 색인을 보존했다. 은행 내부 자료는 사용자가 아직 없다고 확인했으므로 미수집 상태를 유지한다.

## 추가 자료

- [FINTRAC FINTRAC-2023-OA002, July 2023](https://fintrac-canafe.canada.ca/intel/operation/ml-rec-eng): 자동차 판매·수출입 업체 사이 순환 자금 흐름을 관찰한 캐나다 지하금융 사례. 해당 업종·중국/홍콩 관련 분석 맥락을 함께 기록했다.
- [FINTRAC FINTRAC-2024-SB001, January 2024](https://fintrac-canafe.canada.ca/intel/bulletins/gambling-jeu-eng): 온라인 도박 관련 금융기관 사례의 반복 유입·유출과 판단 시 사실·맥락을 함께 보라는 구간.

두 원문은 공식 HTTPS HTML을 받아 버전 번호·문서 월·페이지 수정일·구간을 대조한 후 후보/차이 확인을 거쳐 검색에 반영했다. `cycle_sources.json`과 통합 `corpus_sources.json`에 출처·범위·시행일 미확인(null)을 기록했다. 외국 사례를 한국 법령이나 은행 내규로 분류하지 않는다.

CYCLE의 빈 유형 참고 역할에 두 발췌를 연결했다. 이는 임의의 A→B→C→A 경로에 동일 사례가 적용된다는 판단이 아니다. 그래프만으로 동일 자금·경제적 목적·실소유자 관계·해당 업종/지역을 확인할 수 없으며 보고서의 추가 검토 상태와 사람 검토 요구를 유지한다. 국내 보고 의무의 일반 근거는 기존 법률/고객확인 조문과 구분한다.

## 멘토 검수 준비

[질문 초안 24개](mentor-review-questions.md)를 준비했다. 제안 지원 12·보류 12개이며 전부 검수 대기다. AI 작성 초안의 발췌 존재·자료 범위를 확인했을 뿐 현업 정답 검수를 대신하지 않는다. 이 질문들의 검색 실행은 **0회**이며 성능 수치를 만들지 않았다.

`review_dataset.py`는 원문 버전/인용·질문 범위를 확인하고 검수 미완료 시 `--require-review`를 거부한다. 검수자 코드는 자기 기재 정보이므로 신원을 인증하거나 독립 검수를 증명하지 않는다. 멘토·팀원이 별도로 질문을 직접 작성할 빈 양식도 제공한다. 실제 검수와 새 자료/코드/질문의 고정 후 별도 첫 평가를 진행한다.

```powershell
python rag-service/review_dataset.py
# 현재는 검수 0/24이므로 아래 명령은 중단되는 것이 정상
python rag-service/review_dataset.py --require-review
```

은행 내규는 필요한 구간만 사용 허가를 받아 확보한다. 요청할 항목은 STR 내부 보고 경로·검토 권한/기한·점수 활용 정책·정상 상거래 반론 검토 절차다. 문서명·버전·시행일·허용 사용 범위를 함께 확인한다. 제공 전에는 공개 법률의 내부 통제 의무만 설명하고 KB 실제 결재선·기한·담당자·가중치를 추정하지 않는다.
