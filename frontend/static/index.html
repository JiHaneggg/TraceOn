    원본 근거 확인
    
QUICK GUIDE
    거래 흐름 확인하기
    1. 분석할 거래와 탐지 패턴을 선택합니다.
    2. 핵심 경로에서 집금·분산·순환 구조와 룰 이유를 확인합니다.
    3. 시간순 근거를 누르거나 이전·다음으로 이동하면 해당 송금선이 강조됩니다.
    4. 주변 연결에서 조회 범위의 나머지 거래도 확인합니다.
    5. 관련 근거·검토 초안에서 인용 원문과 수치의 거래 근거를 확인합니다.
    노드의 역할 이름은 화면 설명용입니다. 기업명이나 실소유자 이름이 아니며 전체 계좌 ID는 선택 상세에 표시합니다. 원본 시각에는 시간대 정보가 없습니다. 같은 시각의 거래 순서, 동일 자금 여부, 거래 목적은 이 그래프만으로 확정할 수 없습니다.
